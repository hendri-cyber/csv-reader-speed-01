Fast pure-JavaScript CSV reader for the [make.fun](https://make.fun/bounty/csv-reader-speed-01-run-20261121) "Read broken CSV files faster, 21 November 2026" bounty ($100 in USDC).

`solve.js` parses broken CSV files with a single-pass scanner, about 4.5–5× faster than the baseline. The harness runs `node main.ts` (Node 22): it reads cases from `/input/cases.json` and writes answers to `/output/answers.json`.
